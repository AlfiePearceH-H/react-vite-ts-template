# Project Template

A minimal React and TypeScript template for starting new projects.

## Getting started

```bash
npm install
npm run dev
```

## Commands

```bash
npm run dev     # Opens the project in a test HMR ready web page http://localhost:5173/
npm run build   # Create a production build
npm run preview # Shows the built product
npm run lint    # Check the source files
npm run format  # Formats said file
```

## Includes

- React, Vite, TS
- ESLint
- Prettier
- Husky & Commitlint
- Company css files
